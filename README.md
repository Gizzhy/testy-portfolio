# Oluwatofunmisin Akinwumi — Portfolio

Personal portfolio website for Oluwatofunmisin Akinwumi, Project Manager and PRINCE2 Practitioner based in the Germany.

## About

This is a single-page portfolio built with Next.js, Tailwind CSS, and GSAP animations. It showcases Tofunmi's work experience, key projects, services, and contact details.

## Contact

**Email:** oluwatofunmisin4@gmail.com

## Tech Stack

- [Next.js 15](https://nextjs.org)
- [Tailwind CSS v4](https://tailwindcss.com)
- [GSAP](https://gsap.com) — scroll-triggered animations
- [Lucide React](https://lucide.dev) — icons
- Deployed on [Vercel](https://vercel.com)

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Build

```bash
pnpm build
pnpm start
```
